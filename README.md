1. Problem Statement:

The Restaurant Order Management System is designed to manage food orders using a Singly Linked List. It stores food names, quantities, and prices. The system allows users to add orders, display all orders, and calculate the total bill.

2. Objectives:

1]To develop a Restaurant Order Management System using a Singly Linked List.
2]To store food names, quantities, and prices.
3]To add new food orders dynamically.
3]To display all food orders.
4]To calculate the total bill.
5]To understand the practical application of a Singly Linked List.

3. Introduction

A Restaurant Order Management System is used to manage food orders in a restaurant. In this project, a Singly Linked List is used to store and manage food order information.
Each node contains the food name, quantity, price, and a pointer to the next node. The system allows users to add new orders, display all orders, and calculate the total bill.
This project helps us understand the use of linked lists in real-life applications.

4. Algorithm

Step 1: Start the program.
Step 2: Initialize the head pointer to NULL.
Step 3: Display the menu.
Step 4: Accept the user's choice.
Step 5: If the choice is Add Order, enter the food name, quantity, and price.
Step 6: Create a new node and add it to the end of the linked list.
Step 7: If the choice is Display Orders, display all food details.
Step 8: Calculate the item total using Quantity × Price.
Step 9: Calculate and display the total bill.
Step 10: If the choice is Exit, terminate the program.
Step 11: Repeat the menu until the user selects Exit.
Step 12: Stop.

5. Result

The Restaurant Order Management System was successfully designed using a Singly Linked List in C++. The system allows users to add food orders, display order details, and calculate the total bill. The project demonstrates the practical implementation of a Singly Linked List.

6. Conclusion

This project demonstrates the use of a Singly Linked List for managing restaurant orders. It stores food names, quantities, and prices in individual nodes. The system makes it easy to add and display orders and calculate the total bill.
Through this project, we learned about linked lists, pointers, structures, and dynamic memory allocation in C++. This project helped us understand how data structures can be applied to real-life problems.
